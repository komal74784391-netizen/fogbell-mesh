# Northbeam Data Governance Repository

This repository holds the authoritative policy corpus and dataset-card registry
used by the Northbeam data governance team.

Layout:

- `governance/` — policy code, inspection records, release requests and the
  dataset-card registry.
- `dataset-cards/` — dataset cards for the corpora and artifacts referenced by
  release requests.
- `reviews/` — signed compliance packs for releases.

This repository is the authoritative source. Do not rely on copies held
elsewhere.
