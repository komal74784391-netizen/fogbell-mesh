# Release Request REL-2026-014

Requester: Platform Release Office
Product: Northbeam Code Assistant v2 (open-weight distribution)
Target release date: 2026-12-01
Review reference: NB-RV-32138def

## Scope

The release package includes model weights, tokenizer files and the training
data statement. The data governance team must sign off on the revision map and
the data provenance statement before the package is published.

## Training artifacts

Artifact identifier: code-mini

Declared schema of the released training artifact:

- `blob_id` (string)
- `repo_name` (string)
- `path` (string)
- `length_bytes` (int64)
- `score` (float64)

## Provenance requirements

The provenance record for this artifact must identify the dataset card that
governs the training artifact and the license that applies to redistribution.
The license must be recorded exactly as declared by the governing card.

The compliance pack must contain the revision map and the license attestation,
and a tracking issue must be opened in the release records area before
sign-off.
